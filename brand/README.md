# Evolution Studio identidad digital v1

Este paquete documenta la identidad visual observada en la landing publicada de Evolution Studio al 4 de septiembre de 2026. No reemplaza un manual corporativo aprobado por el cliente ni constituye un registro legal de marca.

## Fuente de verdad

- Landing publicada: `https://evolution-barber.simbytelabs.com/`
- Implementacion local contrastada: `../index.html`
- Referencia de logo disponible: `../assets/reference/evolution-logo-instagram.jpeg`

El HTML local y el publicado son equivalentes. La respuesta publica solo incorpora un script operativo de Cloudflare. El archivo de logo publicado coincide con la referencia local.

## Estado del logo

El archivo disponible es una captura de Instagram, no un logo maestro. El paquete conserva esa referencia sin reconstruirla y no presenta versiones vectoriales, transparentes o monocromaticas como oficiales. Consulte `logo/LOGO-SOURCE-STATUS.md`.

## Contenido

- `evolution-brand-guide.md`: guia editable y versionable.
- `evolution-brand-guide.pdf`: version de presentacion validada visualmente.
- `brand-manifest.json`: inventario de elementos y estado de evidencia.
- `tokens/evolution.tokens.json`: tokens interoperables.
- `tokens/evolution.css`: variables CSS reutilizables.
- `palette/`: lamina de paleta en SVG y PNG.
- `typography/`: especimen, fuentes WOFF2 y licencias OFL.
- `boards/`: resumen visual de una pagina.
- `evidence/`: fuente visual publicada y trazabilidad.
- `tools/`: generadores reproducibles de los artefactos visuales y PDF.

## Regla de uso

Los elementos se clasifican como `verificado`, `inferencia` o `pendiente`. Solo los elementos verificados pueden reutilizarse como expresion exacta de la landing actual. Cualquier ampliacion a papeleria, letreros, uniformes, redes sociales o registro legal requiere validacion adicional del cliente.
